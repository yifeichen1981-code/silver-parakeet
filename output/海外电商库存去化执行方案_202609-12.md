## 二、目标与拆解

**总目标：年底前库存净减 20%，即 7,978 台**（现存 39,889 台 → 目标 31,911 台）

| 来源 | 目标台数 | 说明 |
|---|---|---|
| 自然去化 | 4,096 | 按当前 -1,024 台/月节奏，9–12 月顺延 |
| **专项去化（本方案）** | **3,882** | 在自然节奏之上的增量，由下列四条线完成 |
| 合计 | **7,978** | 达成 20% |

**专项去化四条线：**

| 线 | 对象 | 库存池 | 目标去化 | 性质 |
|---|---|---|---|---|
| **A 清仓出清** | 超 1 年呆滞库存 | 5,570 | **2,600** | 降价清仓 / 批发 / 报废 |
| **B 提前处理** | X100、X110 | 5,839 | **900** | 未呆滞但趋势不可逆，提前动手 |
| **C 动销加速** | C4、X200 | 4,264 | **382** | 新品滞销，促动销而非降价 |
| **D 源头控制** | 中心仓备货 | 9,062 | — | 止住新增，保障 A/B/C 有仓位 |
| | | | **3,882** | |

## 八、追踪机制

**月度追踪四个指标**（建议每月 5 日前出数）：

| 指标 | 起点（7 月末） | 年底目标 |
|---|---|---|
| 总库存台数 | 39,889 | ≤ 31,911 |
| 超 1 年呆滞台数 | 5,570 | ≤ 2,970 |
| 中心仓库存台数 | 9,062 | 环比转负，年底 ≤ 7,500 |
| C4 + X200 可售月数 | 36.2 / 32.9 | ≤ 18 个月 |

**例会机制**：每月一次库存去化例会，电商运营、供应链、财务、品牌四方参加，对四条线进度逐项过账。

## 九、需决策事项

1. **T10 整体 EOL 退市**——1,295 台呆滞（81.3%），五仓分布，月动销为 0，建议一次性清空；
2. **清仓折扣权限**——A 线 30–50% off，B 线（X100/X110）建议 20–35%，需批复价格底线；
3. **超 2 年库存 1,778 台的报废/捐赠额度**——涉及资产减值，需财务口径同步；
4. **中心仓进货冻结范围**——哪些型号可豁免（如已签约的 G50 Max 新品）；
5. **C4 美亚铺货资源**——是否从欧亚/shopify 调拨，或走新一批直发，涉及物流成本；
6. **X200 美亚套餐问题定责**——同套餐 shopify 月销 208 台、美亚仅 5 台，需运营给出诊断与整改方案；
7. **客退品口径核实**——退货仓账面仅 254 台，与"历年累积数千台"的判断差距较大，请确认其余是否已混入各仓正常库存，以便在盘点中区分"可翻新"与"真质量问题"；
8. **考核口径确认**——本方案以台数计。若按库存金额降 20% 考核，需补充各型号单位成本重算（高价机型与低价老款的金额权重差异较大，结论可能变化）。
