# GlocalMe G50 Max 抖音种草推广优化方案（上市势能版 · 素材为核心）

**周期**：7月–8月 ｜ **总预算**：5万（严格闭环）
**核心策略**：以"素材工厂"为中心的三段式上市节奏——**蓄水预埋 → 上市引爆周 → 素材放量**
**版本**：v2.0 ｜ 2026-07-16（基于0716原案优化）

---

## 一、原案三个必须修正的问题

1. **预算不闭环**：原案7月内容1.52w＋投流0.5w≈2w，8月内容3.5w＋投流1.5w＝5w，合计约7w，超出Budget行标注的5w约2万。本版按5万重排，每一笔可加总。
2. **没有"上市时刻"**：原案是7月认知、8月兴趣的平铺两段式，势能=集中度，平铺出不了声量。本版以**上市日为圆心**，前压蓄水、当周引爆、后段放量，把70%的可见声量压缩进上市前后10天。
3. **素材复用链路缺失**：原案置换达人（3-5个→12-15个）只当"白嫖发帖"用。素材为主的正确玩法是：**置换必须签内容授权（星图授权/千川二创），好素材进素材库追投放大**——这是5万预算能打出势能的唯一杠杆。

**口径修正（与天猫详情页案对齐，达人brief强制执行）**：
- "卫星紧急通信"→ 统一"**卫星应急消息**"（现阶段App收发消息，不支持卫星上网——达人口播不得说"没信号也能刷视频"）
- "巅峰性能"→"**旗舰性能**"（"巅峰"在千川/星图审核属高风险用语，素材过审率优先）
- "覆盖全球200+国家"→"**200+国家和地区**"；"182项专利"需法务留证后方可口播
- 产品名统一 **G50 Max**（原案标题写"随身G50"）
- 机上Wi-Fi场景必须带条件表述（需航班提供并允许使用）

## 二、传播主线（与天猫承接页同频）

- **主slogan（品牌资产）**：天地一体 · 环球在握
- **抖音口语版钩子（种草用）**："出国落地就有网，没信号也能报平安"
- **核心心智**：从"上网工具"到"出行装备"的跨越——G50 Max，空天地一体化的全球通信旗舰
- **势能弹药**（每条素材至少带一个）：CES 2026全球首发同款 ｜ 美国官网同售$499.99、全球同步定价 ｜ 天猫首发礼遇
- **人群**：24-45岁，两层打法——
  - 基本盘：商务差旅、出境游、跨国团队、户外探险（原案保留）
  - 溢价盘（新增，对齐¥3499定位）：高净值旅行家、海外置业/陪读家庭、出海企业主——用"轻奢生活方式"账号覆盖

## 三、三段式上市节奏与预算（总计5.0万，数学闭环）

| | **T1 蓄水期**（上市前3周） | **T2 引爆周**（上市日±5天） | **T3 放量期**（上市后至8月底） |
|---|---|---|---|
| **目标** | 埋认知、测素材、攒授权 | 集中声量、打透"新品上市" | 赛马放大、承接转化 |
| **内容定位** | 预埋型：痛点唤醒＋效果对比 | 爆点型：首发事件＋硬核实测 | 复用型：爆款素材追投＋长尾场景 |
| **达人配置** | KOC×2（0.5w）＋素人×6（0.5w）＋**置换×10** | 腰部×1（1.0w）＋KOC×2（0.5w）＋**置换×10集中发布** | 素人×6（0.5w）＋**置换×10** |
| **发布策略** | 错峰试水，筛选跑量脚本 | **48小时内集中发布20+条**，统一话题挂载 | 按素材数据滚动补发 |
| **投流** | 0.3w（小额赛马测素材） | 0.7w（引爆周集中追投爆文） | 1.0w（授权素材千川/随心推放量） |
| **小计** | 1.3w | 2.2w | 1.5w |

- **达人内容合计**：约52-60条（付费17条＋置换30条＋素人自然溢出），较原案41-52条更多，成本更低
- **置换规则（素材工厂核心）**：30台样机置换，入选门槛=同意签**星图内容授权+二创授权（≥30天）**；未授权不置换。目标产出≥30条可投流素材
- **投流总盘2.0w**：全部投给"已验证素材"，不投未经赛马的内容；定向：出国上网/随身WiFi/出境游/商务差旅＋高消费人群包

## 五、执行SOP与考核指标

**素材工厂流程**：脚本模板下发 → 达人初剪48h审核（口径红线检查）→ 发布 → 72h数据回收 → 爆文（完播>25%或互动率>5%）进投流池 → 千川追投 → 每周素材库复盘一次

**KPI（5万盘子的合理预期）**：
| 指标 | 目标 |
|---|---|
| 总曝光 | ≥800万 |
| 有效素材产出 | ≥52条（其中可投流授权素材≥30条） |
| 爆文率（互动率>5%） | ≥10% |
| 抖音"G50 Max/GlocalMe"搜索指数 | 引爆周环比+300% |
| A3种草人群资产 | ≥15万 |
| 天猫店承接 | 引爆周店铺访客环比+100%（与天猫详情页v2.0上线时间对齐） |

**达人brief附录（每单必发）**：统一口径卡（第一节修正项全文）＋ 禁用词表（巅峰/最/第一/绝对/治愈信号焦虑等）＋ 卫星功能演示规范（只拍发消息，不拍刷网页）＋ 授权条款模板
