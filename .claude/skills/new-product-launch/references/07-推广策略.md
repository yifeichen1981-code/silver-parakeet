# 07 推广策略

> 围绕主渠道，把已经验证的产品价值重复打透。
> **输入**：主渠道、主卖点与首批证据 → **输出**：内容媒介组合 + 平台动作 + 引爆点

## 判断原则

1. 推广的起点不是"做什么内容"，而是**用户还缺哪一步才会购买**：没注意、没理解、不相信、觉得不值，还是担心风险？
2. 内容深度要匹配购买参与度。低参与产品先抓注意和尝试，高参与产品必须提供知识、对比、专业证据与风险保障。
3. 不同平台承担不同任务：抖音适合快速测试与放大，小红书适合种草和搜索承接，搜索捕获明确需求，私域负责内测、服务和复购。
4. **引爆点必须放大产品价值并留下搜索与成交。** 一个热闹但与主卖点无关的话题，只会带来短期流量，甚至让用户记住创意却忘记产品。

推广效率来自聚焦和重复：让同一个核心价值，在不同触点被看见、被理解、被相信。

**绿灯检查**：□ 先补决策缺口 □ 深度匹配参与度 □ 爆点服务产品
**避免**：✗ 把同一内容复制到所有平台 ✗ 用无关热点替代价值证明

---

## 工具 1｜决策缺口诊断（先做这一步）

用户卡在哪一环，决定内容任务：

| 缺口 | 内容任务 | 素材方向 |
|------|---------|---------|
| 没注意 | 抓注意力 | 钩子、感官冲击、场景切入 |
| 没理解 | 解释清楚 | 演示、对比、一句话价值 |
| 不相信 | 提供证据 | 数据、测评、真实结果、资质 |
| 觉得不值 | 重构价值 | 替代成本、日均成本、组合价值 |
| 担心风险 | 消除后顾之忧 | 保障、退换、售后、口碑 |

内容全部从 `03-卖点梳理.md` 的**信息屋**取材，不要现场另发明一套说法。

## 工具 2｜参与度 × 内容深度

| 参与度 | 内容任务 | 核心素材 | 媒介组合 | 转化动作 |
|--------|---------|---------|---------|---------|
| 高 | 降低决策风险 | 详细讲解、横评、测评、案例 | 精准人群 + 专业媒体 + 搜索 | 咨询 / 预约 / 留资 |
| 中 | 建立差异偏好 | 场景演示、口碑、对比、品牌主张 | 大众预热 + 垂类种草 + 搜索 | 收藏 / 加购 / 换购 |
| 低 | 抓注意并促尝试 | 感官冲击、利益钩子、社交证明 | 短视频 + 达人 + 促销 | 点击 / 下单 / 复购 |

（参与度在 `01-市场调研.md` 已判断，此处直接沿用，不要重判。）

## 工具 3｜平台分工

**不能复制同一套内容。**

| 平台 | 主任务 | 内容 | 指标 | 起盘动作 |
|------|-------|------|------|---------|
| 抖音 | 快速测试与放大 | 前 3 秒钩子、演示、直播话术 | CTR、停留、CVR、退款 | 先小样测试，再达人/店播放大 |
| 小红书 | 种草与搜索承接 | 场景经验、横评、关键词内容 | SOV、回搜、收藏、咨询 | 先核心高意向词，再扩发现页 |
| 平台搜索 | 承接明确任务 | 品类词、竞品词、需求词页面 | 排名、点击、转化 | 新品先投自己核心词，建立搜索壁垒 |
| 私域 | 内测、共创与复购 | 体验反馈、服务、使用教育 | 活跃、复购、推荐 | 让核心用户成为第一批传播者 |

## 工具 4｜四类引爆点

引爆点必须放大产品价值，而不是让创意盖过产品。

| 类型 | 做法 | 适合 |
|------|------|------|
| 资源爆点 | 在单一渠道/时段形成绝对优势 | 资源充足或能集中预算的项目 |
| 产品爆点 | 把创意做进产品、包装、联名与体验 | 成图率高、用户愿意主动分享 |
| 内容爆点 | 围绕产品主价值设计主动传播话题 | 必须让讨论最终回到新品 |
| 试用爆点 | 降低风险、加入奖励或特殊身份 | 知名品牌或垂直人群 |

**四条准入条件（缺一不做）**：与主卖点强相关 / 目标人群愿参与 / 能留下搜索与成交 / 供应链承接得住。

## 交付物模板

```
【决策缺口】当前用户主要卡在：没注意/没理解/不相信/觉得不值/担心风险
【内容组合】按参与度确定的内容任务、核心素材、媒介组合、转化动作
【平台动作】抖音__ / 小红书__ / 搜索__ / 私域__（主任务、内容、指标、起盘动作）
【内容角度 3–5 个】均标注取自信息屋的哪根支柱
【引爆点方案】类型__ + 四条准入条件逐条核对 + 承接设计（搜索词、落地页、库存）
【衡量】各平台的主指标与停止线
```
