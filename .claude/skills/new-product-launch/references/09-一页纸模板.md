# 附：一页纸上市方案模板

用户要"完整方案"时用这个骨架输出到 `output/<产品名>_新品上市方案.md`。每一格都必须能追溯到前一格——**填不出来就说明上游没做完，回去补，不要编。**

```markdown
# <产品名> 新品上市方案

## 0. 结论先行
- 最危险的假设：
- 当前所处关口：G1 / G2 / G3 / G4（已过 __，卡在 __）
- 本轮要证明的一件事：

## 1. 市场调研 → 机会
- 机会假设：谁 + 场景 + 未满足 + 现替代方案
- 需求证据：证据阶梯第 __ 级（样本/来源/时间）
- 市场类型：新市场×新品牌 / …｜购买参与度：低/中/高
- 最大对手：直接竞品 / 间接竞品 / 旧习惯 / 不行动 → __
- 四维机会评分：需求 _ 差异 _ 盈利 _ 交付 _ ＝ _/20
- **立项结论**：做 / 不做 / 继续验证

## 2. 新品定位
- 原点人群：__（评分与理由）
- 定位句：为__，在__中，我们是__，相比__，凭借__带来__
- 定位规定的"不做"：
- 防御壁垒：难抄证据 / 难抄系统 / 难抄资产

## 3. 卖点梳理
- 核心主张（一句）：
- 主卖点 FABE+O：
- 辅助卖点 ×2–3：
- 信息屋：效果 / 体验 / 信任 三支柱及证据
- 首发主文案（附理解·共鸣·可信·行动评分）

## 4. 上市规划
- 节奏：T-8~T-5 测试 / T-4~T-1 预热 / T 周爆发 / T+1~T+12 脉冲（绑定实际日期）
- 里程碑：M1 可测试 / M2 可预售 / M3 可交付 / M4 可放量（负责人·截止·验收物）
- 爆发前置：M3 可交付 ✓/✗、客服承接 ✓/✗、数据口径 ✓/✗
- 实验卡：假设·变量·样本·周期·主指标·停止线·下一步
- 预算阈值：加码 / 暂停 / 止损

## 5. 产品定价
- 三镜：成本底线（全成本）/ 竞争参照 / 价值上限
- 价格走廊与首发价格点
- SKU 角色：引流 / 利润 / 形象
- 场景价格机制与统一口径
- 边际贡献测算（G3）

## 6. 渠道布局
- 起盘情境：A 集中验证 / B 组合协同
- 主渠道（五项评分）+ 各渠道角色
- 最小成交闭环五环及最薄弱环节
- 预算：学习 20 / 证明 30 / 放量 50 及释放条件
- 扩张闸门现状

## 7. 推广策略
- 决策缺口：没注意 / 没理解 / 不相信 / 觉得不值 / 担心风险
- 内容组合与 3–5 个内容角度（标注取自哪根支柱）
- 平台动作：抖音 / 小红书 / 搜索 / 私域
- 引爆点方案 + 四条准入条件核对

## 8. 复盘迭代
- 90 天节奏与责任人
- 指标口径与看板字段
- Day 14 漏水诊断的触发规则
- 本轮要沉淀的三类资产

## 附：阈值校准说明
本方案中所有分数线与阈值均需按本品类客单价、历史基线和试错成本校准；
未校准前只作为讨论起点，不作为通过标准。
```
