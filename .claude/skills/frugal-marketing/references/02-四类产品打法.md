# 02 四类产品打法

> 目标：按客单价、毛利、决策门槛把产品分四类，各自匹配不同的分销/种草/验证节奏。
> **输入**：产品客单价、毛利结构、决策门槛 → **输出**：对应打法 + 成败关键判断

## 判断原则

1. 客单价决定用户能不能"随便买"——50元以内基本可以冲动决策，直接做规模化分销/直销；50元以上必须先做内容铺垫建立信任。
2. 毛利决定能不能玩分销——分销的本质是拿毛利换达人分成和素材量，毛利不够就撑不起这个体系。
3. 需求真伪必须先验证再投放——垂直细分品最大的风险不是打法不对，而是把"兴趣"误判成"刚需"。
4. 低毛利大单品拼的是品牌力和全域运营效率，不是单点爆发。

**绿灯检查**：□ 先判断客单价与毛利 □ 分销/直销前确认达人体量能否成规模 □ 垂直细分品先做付费测试 □ 低毛利大单品同时兼顾内容与人群资产
**避免**：✗ 低毛利产品硬做分销 ✗ 中高客单价产品跳过种草直接冲量 ✗ 把兴趣热度当真实需求

---

## 类型一｜高毛利大众型产品（客单价 50 元内，如十月稻田玉米）

**分销打法**（推荐，适合大多数非白牌品牌）：
1. 达人分销起量——低成本快速复制爆款
2. 自营账号回收素材——把达人产出的素材证据留存复用
3. 店铺直播承接——搜索流量转化收口

**成败关键**：
- 毛利是否支撑达人分成
- 达人数量是否达到百位级以上（几十个达人做两三个月打不出爆款是正常的，"百"是及格线，"千"才是 80 分——本质是以量取胜）

**直销打法**（适合厦门帮、郑州帮式的多品矩阵玩家）：
- 跑通抖音站内 0→1 闭环（厦门帮）或站外闭环（郑州帮）后，靠海量素材堆满卡位，让素材彼此竞争跑量
- 关键仍是素材量级——素材太少，无论走小红书搜索饱和还是抖音跑量，都撑不起来
- 之后持续优化迭代孵化新品

---

## 类型二｜中高客单价高毛利新物种（如闺蜜机、抗老面霜、BKT）

决策门槛高，用户不能"随便买"，必须先做内容铺垫、跑通种草模型，如果是 nobody 品牌还需要头部达人/明星背书。

**预算充足 → 主攻抖音**：头部达人种草 + 热推放大 + 明星背书 + 全域运营，先起种草声量，再用浅层承接（信息流/搜索）转化，形成"重歌体系循环"（种草蓄水 → 承接转化 → 反哺种草）。

**预算有限 → 从小红书入手，用"正三角模型"**：
- 顶部：垂类专家输出干货内容/方法论，建立专业信任
- 底部：海量 KOC 案例验证效果，形成"大家都在用"的社会认同

**为什么这类产品必须先种草**：相比分销/直销，这类产品用户从"有兴趣"到"下单"的门槛更高、行动成本更高，所以必须把种草做足、精准触达潜在用户，势能积累比即时转化更重要。

---

## 类型三｜垂直细分场景产品（如男性素颜霜、运动防掉耳机）

**首要任务：验证需求真伪，不是设计打法**。核心判断标准："兴趣是假热闹，付费才是真需求。"

**验证方式**：
- 上线付费服务/预售，看是否有人真实付费
- 线下模拟选择实验（AB 选走率测试）：让用户在产品和替代选项之间做真实取舍，观察是否愿意为此放弃替代选项

**投放策略**（需求验证通过后）：
- 精准人群包定向，例如用"金融理财人群"人群包投放财经相关的垂直产品
- 关键词卡位，用招聘相关长尾词等精准词卡位搜索流量

---

## 类型四｜低毛利高性价比大众型产品（如农夫山泉果汁、小度智能屏）

依赖规模效应与生态整合，必须同时兼顾**品牌力建设**和**人群资产积累**，不能只靠单点爆发。

**推广节奏**：平日稳定 + 节点脉冲（详见 `06-抖音小红书联合站打法.md` 的平销期/大促期打法）。

**内容模板三层结构**：
1. 核心卖点表达
2. 视觉形式包装（如果汁倾倒的"血浆质感"）
3. 关键细节呈现（如"果然肉挂壁"的细节镜头）

**判断最优内容模型需三端评估**：
- 前端：CTR 与搜索增长
- 中期：CPUV（单用户获取成本）下降
- 后端：外溢销售（非投放渠道的自然转化）上升

**投放四阶段模型**（预算松紧结合，详见 `06`）：平销降本 → 蓄水扩触达 → 预热抢量 → 爆发收割。

---

## 交付物模板

```
【产品分类】客单价：____  毛利水平：____  决策门槛：高/中/低  → 归类：____
【打法选择】分销 / 直销 / 抖音种草蓄水 / 小红书正三角 / 需求验证 / 全域收割
【成败关键指标】（分销：达人体量是否达百位级 / 需求验证：付费转化率或AB选走率 / 大单品：三端评估指标）
【下一步】需要先做的验证或素材/达人储备是什么，何时可以进入规模化投放
```
