# 07 诊断清单与交付物模板

> 用户描述一个症状时，直接用这张表定位问题、跳转到对应 reference，不要泛泛而谈。

## 症状 → 工具映射表

| 症状 | 大概率原因 | 对应工具 |
|---|---|---|
| 预算被削减但要求保增长 | 还停留在"认知派"或"品效派"单一思路，没有区分新用户认知/老用户行动两套成本 | `01` 核心公式 + 全局四象限诊断 |
| 种草内容效果一次性、无法累积 | 卖点被拆成 N 个人群 N 个说法，或缺了因果认知公式这一环 | `01` 方案解决公式 + 因果认知公式 |
| 达人分销起量后很快被平台限流/被竞品截流 | 落入"低成本新用户行动"陷阱，靠纯佣/坑位费起盘 | `01` 四象限诊断 + `02` 判断真实产品类型该用什么打法 |
| 新品分销打了两三个月打不出爆款 | 达人体量不够（未达百位级及格线）或毛利不支撑分成 | `02` 类型一成败关键 |
| 中高客单价新品转化差 | 跳过了种草蓄水直接冲转化，用户行动门槛没被降低 | `02` 类型二 |
| 上新一个垂直细分品，不确定要不要大力推广 | 还没验证需求真伪，兴趣可能是假热闹 | `02` 类型三需求验证 |
| 不知道预算该往哪个渠道倾斜 | 缺少认知成本测算，只看到了行动成本/ROI | `03` 认知成本公式 |
| 小红书投放 CPC 越来越高但没效果 | 承接笔记本身没有种草力，代理按 CPC 而非回收率筛选笔记 | `03` 回收率筛选 |
| 自然流量占比低，全靠付费 | 没有主动打造自然流爆文，白白浪费免费流量红利 | `03` 自然流爆文四方法 |
| 老用户唤醒成本居高不下 | 没做用户分层，或对厌恶型用户砸钱教育 | `04` 四大降本策略 |
| 双十一/大促投流又降价，利润被侵蚀 | 违反"投流不降价，降价不投流"原则 | `04` |
| 只做新客获取，没做老客深挖 | 忽视交叉销售（比新客转化率高4倍）等低成本增长点 | `04` 提升老用户消费金额 |
| 品牌没预算做大广告，如何建立认知 | 需要用故事三角度+创始人IP路径替代高价广告 | `05` |
| 团队互相甩锅，说不清谁该对增长负责 | 团队按职能（内容组/投流组）而非按结果（新用户认知组/老用户提醒组）拆分 | `05` 端到端闭环小组 |
| 新品该主推抖音还是小红书 | 先判断产品类型和预算规模，再看生命周期阶段 | `02` + `06` |
| 大促快到了但还没开始种草 | 时机已晚——种草内容需要提前两三个月铺设 | `06` 大促期 |
| 抖音种草被白牌低价收割/A3成本高 | 需要短中期分层解法，而非加大投放金额 | `06` 进阶打法一 |

## 全案交付物模板（系统诊断/搭建增长模型时使用）

```
# <产品名> 穷营销方案

## 象限诊断
当前打法落在四象限的哪一格：____
判断依据：____

## 新用户认知
方案解决公式：谁/情境____ + 问题____
因果认知公式：因为____，所以____，能解决____
两个检验：符合常识____ / 非行业人士秒懂____
核心品牌音（本轮所有内容重复强化）：____

## 产品打法
分类：客单价____ 毛利____ 决策门槛____ → 类型：____
对应打法：____
成败关键指标：____

## 预算配置
认知成本对比（各渠道）：____
行动成本优选标准：____
小红书预算配比：搜索__% 信息流__% 自然流__%

## 抖音/小红书阶段打法（如涉及）
当前生命周期阶段：____
测试顺序 / 爆发主阵地 / 阶段任务：____

## 老用户唤醒
分层方式：____
轻提醒手段：____
目标行动成本：从____降到____

## 品牌与团队
品牌故事角度：____
团队架构（认知组/行动组）：____

## 衡量与复盘节点
认知成本趋势：____
行动成本趋势：____
用户量与收入曲线：____
下次复盘时间：____
```

单点问答场景不需要套用全案模板，直接在对话中给出对应 reference 的结论即可。
