# 06 抖音小红书联合站打法

> 目标：不是"选一个平台"，而是把抖音和小红书的资源、节奏整合起来，实现 1+1>2——用更少预算带来更大增长，这本身就是穷营销的一种落地途径。
> **输入**：产品生命周期阶段（新品上市/平销/大促）、产品特性、预算规模 → **输出**：分阶段的双平台任务分工和执行动作

## 判断原则

1. 抖音和小红书不是二选一，是**营销人的思维方式**——站在业务和生意的角度看，两个平台都只是营销工具（达人种草、KOC、效果广告都是工具），核心问题永远是"怎么组合才能花更少的钱拿到更大增长"。
2. 两平台角色互补，不能用同一套内容复制粘贴：抖音负责"大曝光 + 快转化"，小红书负责"深化认知 + 搜索承接"。
3. 打法要按产品生命周期阶段切换：新品上市期先测试后爆发，平销期做稳固+拓量+防守，大促期提前铺垫、正周期收割。

**绿灯检查**：□ 先在小红书低成本测种草模型 □ 按预算规模决定新品爆发主阵地 □ 平销期三任务同时进行 □ 大促内容提前2-3个月铺垫
**避免**：✗ 同一套素材直接搬运到两个平台 ✗ 大促期才开始种草 ✗ KOC 盲目铺量不做长线关系

---

## 平台特点与营销角色对比

| 维度 | 抖音 | 小红书 |
|---|---|---|
| 用户特点 | 体量庞大，群体相对泛化，娱乐流量舞台 | 购买力强、转化型+社交型用户，习惯购买前查看评价 |
| 流量特征 | 爆发性强，头部 KOL 流量集中效应强；种草新规对头部/剧情类达人的内容植入限制严格 | 长尾性强，对 KOC 和素人账号流量支持多，干货内容易获流量 |
| 营销角色 | 大流量获取平台，适合大曝光种草+快速转化，脉冲式大爆发拓人群，大单品传播阵地 | 搜索承接平台，深化认知、催化营销，适合长线内容铺垫和口碑建设，按"反漏斗"逻辑层层渗透 |

## 阶段一｜新品上市期

### 内容测试

**测试顺序建议**：先小红书测最优种草模型，再抖音测最优转化模型。原因：小红书测试成本低、周期短、干扰少，且可用图文测试（不需要拍视频）。

**小红书测试要点**：测的是"种草力"而非"爆文"，关注封面标题点击率、投流后回搜率、深度种草和转化效果（如 CPUV 成本、闭环 ROI）。

执行流程（以无屏早教机为例）：批量 KOC 发布笔记 → 少量全站直投筛选出点击率和阅读量好的笔记 → 放大投流并关注回搜率 → 找出真正的痛点切入点 → 批量复制优化内容模型。

**抖音测试要点**：适合高毛利大众型、决策链路短、依赖视频冲击力的产品，以及垂类细分且人群在抖音有优势的产品。测的是"转化最优模型"，关注 ROI、CTR、CVR、CPM 和高点击画面。

执行流程：批量垂类 KOC 达人在上市两周内发布，挂车投放 → 复盘分析高 ROI 内容形式、关键画面和卡审点。

### 新品爆发

**预算允许 → 侧重抖音**：流量高爆发、体量大，能快速实现大渗透和转化（如闺蜜机新品上市主阵地放在抖音）。

打爆策略：
1. 组合头部 + 剧情号达人做出强种草爆款，起势破圈
2. 配合垂类达人深度种草、反复触达人群
3. 用种草通、内容热推、原生竞价投流实现人群破圈和收割

**预算有限或客单高/需求窄/教育成本高 → 侧重小红书**：先用 KOL 获取信任，再配合 KOC 输出真实使用感内容（如泡泡骚通过垂类达人输送干货形成购买潮流，再用 KOC 跟风造势破圈）。

**预算组合搭配**：抖音聚焦上市关键节点打造传播大脉冲、拉高声量；小红书做长线口碑铺设、组合种草，提高种草效率。

## 阶段二｜平销期

三大核心任务同时进行：

| 任务 | 小红书动作 | 抖音动作 |
|---|---|---|
| **稳固** | 用 KOL/KOC 长线种草持续复用新品期测出的有效种草模板 | 用 KOC 增加种草体效 |
| **拓量破圈** | 配合 DMP 人群包做探索测试，探索自然流爆文 | 围绕电商小促节点或合作明星/头部达播打造小脉冲节点，整合资源制造声量 |
| **防守** | 抢占 SEO 机会，监控舆情，布局搜索关键词内容 | 做好小蓝词防守、品专和品类词挑战，内容热推做精准人群破圈 |

### 小红书 SEO 布局细化

内容分层：
- **本品词**：买品专防守，铺产品真实体验口碑内容
- **品类词/竞品词**：做选购历程内容，用头部 KOL 和明星产品背书影响摇摆人群

时机：平销期是小红书抢占 SEO 的最佳时机——此时新品已累积声量，搜索广告竞争相对少。关注蒲公英后台上下游词：上游词找潜力增量词，下游词监测口碑和防守重点。

### 抖音 KOC 打法细化

**利益点**：KOC 爆款视频可以盘活老品；品牌做 KOC 相比素人有品牌声量加持和产品矩阵丰富的优势；可将 KOC 作为种草提效手段，同时考虑其种草外溢和素材投流成本 ROI。

**注意事项**：
- 不要盲目铺量，与达人建立长线关系，筛选出销冠和内容素材库
- 选品可考虑长尾品，注重场景画面和利润纵深
- 避免用低客单产品吸引流量或卖小样——这会拉低品牌调性且难以沉淀真实购买用户

### 抖红联合提效手段（平销期）

| 手段 | 做法 |
|---|---|
| 红书内容同步抖音 | 将小红书优质种草内容免费或少量付费同步到抖音，增加双平台优质内容量，储备投流素材 |
| 红书配合明星达播造节 | 先在小红书做 KOC 购买攻略和小达人种草，直播后用直播切片素材投闭环，打造产品与明星小爆款 |
| 红书搜索卡词内容同步抖音 | 把小红书表现好的 SEO 爆文搬运到抖音，吃搜索流量 |

## 阶段三｜大促期

**整体节奏**：关键是快速转化，放大转化投放效果。种草内容要提前两三个月铺设，大促节点只做效果收割转化。

**抖音策略**：
- 大促正周期做能带来声量的头部达人拉高搜索指数，吸引进店
- 伪垂素材提前两个月储备并配合投流测试，找到能吃住量的素材
- 确保核心卖点和核心画面贯穿千川投放和直播间流程，提高转化率

**小红书策略**：
- 前序铺垫真实口碑内容
- 大促节点用闭环流量（买手比价、大促攻略等）吸引购买
- 缩量信息流，放大搜索投流和直接效果投放

**错位竞争案例（非头部玩家适用）**：卷不动正面大促节点时，可做时间节点和渠道的错位竞争——例如痘肌美妆品牌选择 1 月年货节而非双十一/双十二，诺梵松露巧克力聚焦双旦、春节送礼场景，主阵地放在抖音，集中预算在核心时间节点实现爆破。

## 抖红联合站三个进阶打法

### 进阶一｜解决抖音种草难题（被白牌低价收割、A3转化率低、垂类达人内容同质化）

| 时效 | 解法 |
|---|---|
| 短期 | 爆视频/VLOG 内容铺量，投流交集行业人群，用不同素材触达同一类精准人群提高渗透率后收割 |
| 中期 | 除爆款内容外，关注垂类达人 CP 的 A3 成本和 SPUA3，用垂类达人素材收割行业人群 |
| 降本提效 | 找大量低成本、低粉但有热点内容的达人合作，以低成本打爆发，吸引行业人群进入品牌人群池 |

### 进阶二｜最大化新素材

**测试**：小红书用 KOC 矩阵配合投流测试；抖音用千川投放效果广告测试。

**素材流动与改造**（两平台互相验证放大）：
- 小红书测出的好素材：让千川供应商产出对应素材验证效果，也可以直接投放看 CAC 成本和 ROI
- 抖音千川测出的好素材：放到小红书用腰尾达人 KOC 种草，利用其中的关键画面
- 改造方法：红书素材搬到抖音，采用"三倍化开头"（前几秒信息密度提高三倍抓注意力）；抖音素材搬到红书，在封面和标题突出痛点场景和对比，标题用干货攻略式表达吸引点击率

### 进阶三｜全域放大优质自然爆款内容

把抖音、小红书的优质自然爆款内容同步放大到全域，同时贯穿品牌主线不漂移。案例：小度的有趣语料可以在小红书做 KOC 自然流笔记、在抖音千川做效果广告、在品牌长视频中体现，同时始终贯穿同一条品牌主线（如"小度在家，陪伴在家"）。
